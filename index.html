BAB 2. BERPIKIR KOMPUTASIONAL

Berpikir komputasional melatih kita menyelesaikan masalah keseharian di sekolah dengan cara yang runtut, logis, dan hemat waktu.

A. Algoritma (Urutan Langkah & Percabangan Sekolah)

Algoritma adalah urutan langkah logis untuk menyelesaikan suatu aktivitas. Dalam keseharian di sekolah, kita sering menemui aturan kondisi Jika–Maka (If–Else) saat mengambil keputusan.

B. Optimasi Penjadwalan (Paralel vs Serial)

Optimasi penjadwalan adalah mengatur urutan tugas agar selesai dalam waktu paling singkat. Pekerjaan yang menggunakan mesin atau tidak saling menunggu dapat dikerjakan bersamaan (paralel).

C. Struktur Data: Stack (Tumpukan) & Queue (Antrean)

Struktur data mengatur cara menyimpan dan mengambil data. Di sekolah, kita melihatnya pada tumpukan buku tugas dan antrean kantin, selain juga struktur pohon (Tree) pada bagan organisasi OSIS dan graf (Graph) pada denah koridor kelas.

D. Representasi Data (Sandi & Kode Biner Kehadiran)

Representasi data adalah cara menyajikan informasi dalam bentuk simbol, angka, atau kode biner (1 = Hadir/Ya, 0 = Tidak Hadir/Tidak) agar mudah dibaca sistem.

BAB 3. TEKNOLOGI INFORMASI DAN KOMUNIKASI (TIK)

Mengelola berkas digital secara rapi dan menguasai aplikasi perkantoran akan memudahkan kamu mengerjakan berbagai tugas sekolah di laptop, ponsel pintar (HP), maupun penyimpanan awan (Cloud).

A. Folder dan File (Ekstensi & Pengelolaan di Laptop, HP, dan Cloud)

File adalah berkas data digital yang memiliki nama dan ekstensi (akhiran setelah tanda titik untuk mengenali jenis aplikasinya), sedangkan Folder adalah wadah untuk mengelompokkan file agar mudah dicari.

Kategori File Ekstensi Populer Aplikasi Pembuka & Kegunaan
Dokumen Teks .docx, .doc, .pdf, .txt Microsoft Word, Google Docs, Adobe Reader (Makalah, surat, e-book)
Lembar Kerja / Angka .xlsx, .xls, .csv Microsoft Excel, Google Sheets (Jadwal piket, daftar nilai, tabel keuangan)
Presentasi .pptx, .ppt Microsoft PowerPoint, Google Slides, Canva (Materi presentasi kelompok)
Gambar / Foto .jpg, .jpeg, .png, .svg Galeri Foto, Paint, Canva (Dokumentasi kegiatan, poster tanpa latar belakang)
Audio & Video .mp3, .wav | .mp4, .mkv Pemutar Musik & Video, CapCut (Rekaman suara, tugas video praktik)
Arsip / Kompresi .zip, .rar WinRAR, File Explorer (Menggabungkan banyak file tugas menjadi satu paket)
  • Pengelolaan di Laptop & HP: Gunakan Copy–Paste untuk menggandakan file, Cut–Paste untuk memindahkan file, Rename untuk mengubah nama, dan Recycle Bin / Trash untuk memulihkan (Restore) file yang tidak sengaja terhapus. Di HP, gunakan aplikasi File Manager / Files untuk memindahkan data dari memori internal ke kartu SD agar memori tidak penuh.
  • Pengelolaan di Cloud Storage (Google Drive / OneDrive): File tersimpan aman di server internet sehingga bisa diakses dari laptop maupun HP. Saat membagikan tautan tugas kelompok, atur hak aksesnya: Viewer (hanya lihat), Commenter (beri komentar), atau Editor (bisa ikut mengetik dan mengedit bersama).

B. Aplikasi Perkantoran (Pengolah Kata, Tombol Kombinasi & Ketik Cepat)

Perangkat lunak pengolah kata (seperti Microsoft Word dan Google Docs) digunakan untuk membuat surat, laporan, makalah, dan artikel. Berikut adalah bagian-bagian penting jendela kerja dan cara pengerjaan dokumen yang rapi:

Urutan Cara Pengerjaan Dokumen Laporan yang Benar: (1) Atur ukuran kertas (A4/F4), orientasi (Portrait/Landscape), dan batas tepi (Margins) di menu Layout / Page Setup → (2) Ketik seluruh naskah terlebih dahulu → (3) Format judul (Center + Bold) dan isi paragraf (Justify) → (4) Sisipkan tabel atau gambar melalui tab Insert → (5) Simpan dokumen (Ctrl + S).

Latihan Interaktif BAB 3 (Folder/File, Pengolah Kata & Uji Ketik Cepat) Uji pemahamanmu tentang ekstensi file, fitur pengolah kata, dan ukur kecepatan mengetikmu (WPM)!

BAB 4. SISTEM KOMPUTER (HARDWARE & SOFTWARE)

Sistem komputer terdiri dari tiga komponen utama yang saling bekerja sama: Hardware (perangkat keras/fisik), Software (perangkat lunak/program), dan Brainware (pengguna manusia).

A. Perangkat Keras (Hardware) — Kategori, Perangkat & Fungsinya

Perangkat keras (Hardware) adalah seluruh komponen fisik komputer yang dapat dilihat dan disentuh secara langsung. Berikut pembagian 4 kategori lengkapnya:

Kategori Hardware Nama Perangkat Keras Fungsi Utama Perangkat
1. Perangkat Masukan
(Input Device)		 Keyboard Memasukkan data berupa huruf, angka, simbol, dan perintah tombol pintas.
Mouse / Touchpad Menggerakkan kursor/penunjuk di layar dan memilih menu (klik).
Scanner (Pemindai) Memindai dokumen kertas atau foto fisik menjadi file gambar/PDF digital.
Microphone Menangkap gelombang suara dari luar untuk direkam ke dalam komputer.
Webcam / Barcode Scanner Webcam menangkap gambar/video langsung; Barcode Scanner membaca kode batang barang/buku.
2. Perangkat Pemroses
(Process Device)		 Processor (CPU) Otak utama komputer yang menjalankan seluruh perhitungan logika dan instruksi program.
RAM (Random Access Memory) Memori penyimpanan sementara saat aplikasi sedang berjalan (isi hilang jika listrik mati).
Motherboard (Papan Induk) Papan sirkuit utama tempat menempel dan terhubungnya seluruh komponen hardware.
VGA Card / GPU Mengolah data grafis/visual agar tampil tajam dan halus di layar monitor.
3. Perangkat Keluaran
(Output Device)		 Monitor Menampilkan hasil pengolahan data secara visual (teks, gambar, video) di layar.
Printer Mencetak dokumen digital menjadi bentuk fisik di atas kertas (hardcopy).
Speaker / Headphone Mengeluarkan hasil pengolahan data berupa gelombang suara/audio.
Proyektor (LCD Projector) Memancarkan tampilan layar komputer ke bidang layar lebar/dinding untuk presentasi.
4. Perangkat Penyimpanan
(Storage Device)		 Harddisk Drive (HDD) Media penyimpanan internal berkapasitas besar menggunakan piringan magnetik berputar.
Solid State Drive (SSD) Media penyimpanan modern berbasis chip memori; jauh lebih cepat dan tahan guncangan daripada HDD.
Flashdisk & Memory Card Media penyimpanan eksternal berukuran kecil yang mudah dibawa dan dipindahkan antar perangkat.

B. Perangkat Lunak (Software) — Kategori, Contoh & Fungsinya

Perangkat lunak (Software) adalah sekumpulan instruksi atau program digital yang tidak berwujud fisik, berfungsi mengendalikan perangkat keras agar dapat digunakan manusia. Berikut 4 kategori utamanya:

Kategori Software Contoh Perangkat Lunak Fungsi & Kegunaan Utama
1. Sistem Operasi
(Operating System)		 Windows, macOS, Linux (Komputer/Laptop); Android, iOS (Smartphone) Perangkat lunak induk yang mengatur seluruh kerja hardware, mengelola file, dan menjadi jembatan agar aplikasi lain bisa berjalan.
2. Perangkat Lunak Aplikasi
(Application Software)		 • Pengolah Kata: MS Word, Google Docs
• Pengolah Angka: MS Excel
• Presentasi: MS PowerPoint, Canva
• Peramban (Browser): Google Chrome, Edge		 Digunakan langsung oleh pengguna untuk menyelesaikan pekerjaan spesifik sehari-hari seperti mengetik laporan, menghitung tabel, desain poster, atau menjelajah internet.
3. Perangkat Lunak Pemrograman
(Programming Software)		 Scratch, Python, C++, JavaScript, Visual Studio Code Digunakan oleh pemrogram (programmer) untuk menulis kode dan menciptakan aplikasi, situs web, atau permainan baru.
4. Perangkat Lunak Utilitas
(Utility Software)		 Windows Defender / Smadav (Antivirus), WinRAR / 7-Zip (Kompresi), Disk Cleanup Membantu merawat kinerja komputer, membersihkan file sampah sementara, memampatkan ukuran file, dan melindungi sistem dari serangan virus/malware.
