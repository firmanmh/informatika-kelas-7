BAB 2. BERPIKIR KOMPUTASIONAL

Berpikir komputasional membantu kita memecahkan masalah sehari-hari di sekolah dengan pola pikir yang logis dan sistematis layaknya komputer.

A. Algoritma & Logika Keseharian

Algoritma adalah urutan langkah logis untuk menyelesaikan masalah. Di sekolah, kita sering menggunakan aturan percabangan (If-Then-Else).
Contoh: "JIKA hujan turun, MAKA upacara dilakukan di kelas. JIKA TIDAK, MAKA upacara di lapangan."

B. Optimasi Penjadwalan (Paralel vs Serial)

Mengatur urutan pekerjaan agar selesai secepat mungkin. Tugas yang tidak saling bergantung bisa dikerjakan bersamaan (paralel) untuk menghemat waktu.

C. Struktur Data: Stack vs Queue

Ada dua cara mengurutkan benda atau antrean dalam dunia komputer maupun keseharian sekolah:

  • STACK (Tumpukan - LIFO): Last In First Out (Masuk Terakhir, Keluar Pertama).
    Contoh: Tumpukan buku PR di meja guru. Buku yang ditaruh paling akhir (paling atas) akan diperiksa paling pertama.
  • QUEUE (Antrean - FIFO): First In First Out (Masuk Pertama, Keluar Pertama).
    Contoh: Antrean kantin. Siswa yang datang pertama (paling depan) akan dilayani pertama.

D. Representasi Data

Cara menyajikan informasi agar mudah diproses. Contoh sederhana adalah menggunakan kode Biner (hanya angka 1 dan 0). Di sekolah, guru mengabsen dengan kode biner: 1 = Hadir/Ya, 0 = Tidak Hadir/Absen.

BAB 3. TEKNOLOGI INFORMASI & KOMUNIKASI (TIK)

Bab ini membahas pengelolaan file digital secara aman dan rapi, serta cara mengoperasikan aplikasi perkantoran dengan trik cepat.

A. Pengelolaan Folder, File & Cloud Storage

Ekstensi File (Akhiran Nama) Jenis Aplikasi/Kegunaan
.docx Dokumen teks (Microsoft Word, Google Docs)
.xlsx Tabel & angka (Microsoft Excel, Google Sheets)
.pptx Presentasi slide (Microsoft PowerPoint)
.jpg / .png Gambar atau foto digital
☁️ Bekerja Kelompok di Cloud (Google Drive)

Jika menyimpan file di Cloud, kamu bisa membagikan aksesnya ke temanmu:
• Viewer: Temanmu hanya bisa melihat/membaca saja.
• Commenter: Bisa melihat dan memberi catatan/komentar.
• Editor: Temanmu bisa ikut mengetik, mengubah, dan menghapus isi file bersamamu.

B. Aplikasi Perkantoran: Pengolah Kata & Mengetik Cepat

Pada aplikasi pengolah kata, terdapat alat bernama Ribbon (kumpulan ikon menu). Fitur perataan teks meliputi: Align Left (Kiri), Center (Tengah), Align Right (Kanan), dan Justify (Rata Kiri-Kanan).

Tombol Pintas (Shortcut) Penting:

  • Ctrl + C & Ctrl + V (Copy-Paste): Menggandakan file/teks (file asal tetap ada).
  • Ctrl + X & Ctrl + V (Cut-Paste): Memindahkan file/teks (file asal dipindah/hilang).
  • Ctrl + Z (Undo): Membatalkan kesalahan terakhir (misal tidak sengaja menghapus teks).
  • Ctrl + B (Bold - Tebal), Ctrl + I (Italic - Miring), Ctrl + U (Underline - Garis Bawah).

BAB 4. SISTEM KOMPUTER

Komputer tidak bisa menyala sendiri. Agar bisa bekerja, dibutuhkan 3 unsur utama yang saling berkolaborasi: Hardware (Fisik) + Software (Program) + Brainware (Manusia/Pengguna).

A. Perangkat Keras (Hardware)

Wujud fisik komputer yang bisa disentuh. Terbagi menjadi 4 fungsi utama:

Kategori Fungsi Utama Contoh Perangkat
Input (Masukan) Memasukkan data atau perintah Keyboard, Mouse, Scanner, Microphone
Process (Pemroses) Otak komputer yang mengolah data Processor (CPU), RAM (Memori sementara)
Output (Keluaran) Menampilkan hasil olahan data Monitor, Printer, Speaker, Proyektor
Storage (Penyimpanan) Menyimpan file jangka panjang Harddisk (HDD), SSD (Lebih cepat!), Flashdisk

B. Perangkat Lunak (Software)

Program tak kasat mata yang berisi kumpulan perintah. Terdiri atas:

  • Sistem Operasi (OS): Pengelola sistem utama (Contoh: Windows, macOS, Android, iOS).
  • Aplikasi Perkantoran/Utilitas: Program untuk fungsi spesifik (Contoh: Ms. Word, Chrome, CapCut).
  • Perangkat Lunak Utilitas: Pemelihara keamanan dan kinerja PC (Contoh: Antivirus, Disk Cleanup).
  • Bahasa Pemrograman: Alat pembuat aplikasi (Contoh: Scratch, Python).
