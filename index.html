BAB 1: BERPIKIR KOMPUTASIONAL (COMPUTATIONAL THINKING)

Berpikir Komputasional adalah kerangka pemecahan masalah dengan menirukan cara kerja sistematis, logis, dan terstruktur. Terdapat 4 pilar utama:

  • Dekomposisi: Memecah masalah besar menjadi bagian-bagian kecil yang lebih sederhana.
  • Pengenalan Pola: Mencari kesamaan atau keteraturan dari berbagai data/masalah.
  • Abstraksi: Memfokuskan diri hanya pada informasi penting dan mengabaikan detail yang tidak relevan.
  • Algoritma: Menyusun langkah-langkah penyelesaian masalah secara berurutan dan logis.

BAB 2: PENGELOLAAN FILE DAN FOLDER (UNPLUGGED)

Data digital disimpan dalam bentuk file dan dikelompokkan ke dalam wadah bernama folder menggunakan sistem hierarki (pohon direktori) agar mudah ditemukan kembali. Setiap file memiliki ekstensi di belakang namanya untuk mengenali format aplikasi pembukanya.

BAB 3: PENGOLAH KATA & KETIK CEPAT (MAX 30 WPM)

Aplikasi pengolah kata digunakan untuk mengetik dokumen resmi. Siswa kelas 7 dilatih membiasakan teknik 10 jari (*touch typing*) dengan target kecepatan hingga 30 WPM (Words Per Minute) serta menjaga akurasi tinggi.

BAB 4: PERANGKAT KERAS KOMPUTER (HARDWARE)

Komputer mengolah data melalui siklus komputasi dasar:

Input (Masukan) ➔ Process (Pemrosesan) ➔ Output (Keluaran) ➔ Storage (Penyimpanan)

Rincian Komponen Perangkat Keras & Visualisasinya:

⌨️
Keyboard (Papan Ketik)
Perangkat input utama berisi deretan tombol huruf standar QWERTY dan angka untuk memasukkan teks.
🖱️
Mouse (Tetikus)
Alat penunjuk genggam dengan tombol klik kiri/kanan dan scroll wheel untuk menggerakkan kursor.
🔲
CPU / Processor
Kepingan silikon kotak berukuran kecil sebagai "otak" pusat pengolah seluruh instruksi logika komputer.
🧩
Motherboard
Papan sirkuit cetak utama tempat seluruh komponen hardware terhubung dan dialiri listrik.
🧠
RAM (Memori Utama)
Kepingan sirkuit tipis memanjang untuk menampung data program yang sedang berjalan secara sementara.
💾
Harddisk / SSD
Kotak logam penyimpan data sekunder permanen berkapasitas besar untuk file dan sistem operasi.
🖥️
Monitor (Layar)
Perangkat output berlayar datar tipis yang menampilkan antarmuka visual kepada pengguna.
🖨️
Printer (Mesin Cetak)
Perangkat output untuk mencetak hasil pengolahan data digital ke atas lembaran kertas fisik.
