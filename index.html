BAB 1: BERPIKIR KOMPUTASIONAL (COMPUTATIONAL THINKING)

Berpikir Komputasional adalah metode pemecahan masalah dengan mengandalkan cara kerja yang logis, sistematis, dan terstruktur. Di dalam kehidupan sehari-hari, kita sering menggunakannya tanpa sadar melalui 4 pilar utama:

🧩
1. Dekomposisi
Memecah masalah besar menjadi bagian kecil.

Contoh Sehari-hari: Saat kamar tidur sangat berantakan, kita tidak merapikannya sekaligus, melainkan membaginya menjadi: merapikan tempat tidur, menyapu lantai, lalu melipat pakaian di lemari.
🔍
2. Pengenalan Pola
Mencari kesamaan atau kebiasaan yang berulang.

Contoh Sehari-hari: Melihat jadwal seragam sekolah setiap hari Rabu selalu mengenakan baju batik hijau, sehingga kita menyiapkan pakaian batik tersebut setiap Selasa malam secara berulang.
🏷️
3. Abstraksi
Fokus pada informasi penting, abaikan detail.

Contoh Sehari-hari: Saat melihat peta rute dari rumah ke sekolah, kita hanya melihat garis jalan utama dan petunjuk arah belok, tanpa perlu memikirkan jumlah pohon atau warna pagar rumah tetangga.
📋
4. Algoritma
Menyusun urutan langkah logis untuk solusi.

Contoh Sehari-hari: Urutan mencuci tangan yang benar: 1. Basahi tangan, 2. Beri sabun, 3. Gosok telapak & sela jari, 4. Bilas dengan air mengalir, 5. Keringkan dengan handuk.

BAB 2: PENGELOLAAN FILE DAN FOLDER (UNPLUGGED)

1. Teori Dasar File dan Folder

Dalam dunia digital, data dan informasi disimpan di dalam perangkat penyimpanan komputer ke dalam satuan terkecil bernama File (Berkas). Setiap file memiliki nama serta akhiran yang disebut Ekstensi File (misalnya .docx, .jpg, .mp3) untuk memberi tahu sistem aplikasi apa yang bisa membuka file tersebut.

Agar file-file tersebut tidak tercecer dan mudah ditemukan kembali, kita menggunakan wadah penyimpanan digital bernama Folder (Direktori). Pengorganisasian folder disusun menggunakan sistem berjenjang atau bercabang yang disebut Pohon Direktori (*Folder Hierarchy*), mulai dari Folder Utama (*Root*), masuk ke Sub-Folder kategori, hingga berisi file di dalamnya.

BAB 3: PENGOLAH KATA & KETIK CEPAT (MAX 30 WPM)

1. Teori Aplikasi Pengolah Kata (*Word Processor*)

Pengolah Kata adalah perangkat lunak (*software*) yang dirancang khusus untuk membuat, menyunting, memformat, dan mencetak dokumen berbasis teks seperti surat resmi, laporan, makalah, dan artikel.

  • Jenis Aplikasi:
    • Versi Desktop (Komputer/Laptop): Microsoft Word, LibreOffice Writer, WPS Office (memiliki fitur tata letak cetak dan instrumen tingkat lanjut).
    • Versi Seluler / Cloud (HP/Tablet/Browser): Google Docs, Microsoft Word Mobile (unggul dalam kolaborasi waktu nyata dan penyimpanan otomatis di awan/*cloud*).
  • Keterampilan Ketik Cepat (Target 30 WPM): *WPM (Words Per Minute)* adalah satuan kecepatan mengetik. Siswa kelas 7 dilatih membiasakan teknik 10 jari (*touch typing*) dengan target pencapaian hingga **30 WPM** dengan tetap mengutamakan **akurasi tinggi (minim salah ketik / *typo*)**.

BAB 4: PERANGKAT KERAS KOMPUTER (HARDWARE)

1. Siklus Pengolahan Data Komputer

Perangkat keras (*hardware*) adalah seluruh komponen fisik komputer yang dapat dilihat dan disentuh. Dalam memproses data, komputer selalu mengikuti alur siklus komputasi yang runtut:

📥 INPUT (Masukan) ➔ ⚙️ PROCESS (Pemrosesan) ➔ 📤 OUTPUT (Keluaran) ➔ 💾 STORAGE (Penyimpanan)

2. Rincian Lengkap Komponen Perangkat Keras

1. Perangkat Masukan (Input Device)

Perangkat yang digunakan untuk memasukkan data, teks, gambar, atau perintah dari pengguna ke dalam sistem komputer.

Input Device
⌨️
Keyboard (Papan Ketik)
Papan berisi tombol huruf QWERTY, angka, dan fungsi khusus untuk mengetik teks dan memberikan perintah.
Input Device
🖱️
Mouse (Tetikus)
Alat penunjuk genggam untuk menggerakkan kursor di layar serta melakukan klik dan gulir.
Input Device
📷
Scanner & Webcam
Alat pemindai dokumen kertas atau kamera penangkap objek visual/video ke dalam komputer.
Input Device
🎤
Microphone
Perangkat yang menangkap gelombang suara atau audio dari luar untuk direkam atau dimasukkan ke sistem.

2. Perangkat Pemroses (Process Device)

Komponen utama yang berfungsi sebagai "otak" untuk mengolah, menghitung, dan mengeksekusi seluruh perintah data.

Process Device
🔲
CPU / Processor
Kepingan silikon pusat pengolah data utama yang menjalankan seluruh instruksi perangkat lunak dan logika.

3. Perangkat Keluaran (Output Device)

Perangkat yang menampilkan, menyajikan, atau mencetak hasil akhir pengolahan data agar dapat dibaca oleh pengguna.

Output Device
🖥️
Monitor (Layar)
Layar penampil visual yang menyajikan antarmuka gambar, video, dan teks secara langsung kepada pengguna.
Output Device
🖨️
Printer
Perangkat pencetak untuk menyalin data digital dari komputer ke atas permukaan lembaran kertas fisik.
Output Device
🔊
Speaker / Headset
Perangkat akustik untuk menghasilkan dan mengeluarkan gelombang suara atau musik dari komputer.
Output Device
📽️
Projector
Alat pemancar sorot cahaya untuk memperbesar tampilan layar komputer ke dinding atau layar besar.

4. Perangkat Penyimpanan (Storage Device)

Media penampung data, file, aplikasi, dan sistem operasi baik secara sementara maupun permanen.

Storage Device
🧠
RAM (Memori Utama)
Memori sementara berkecepatan tinggi untuk menampung data program yang sedang aktif berjalan.
Storage Device
💾
Harddisk (HDD) & SSD
Penyimpanan sekunder permanen berkapasitas besar untuk menyimpan seluruh file dokumen dan sistem operasi.
Storage Device
🔌
Flashdisk & Kartu Memori
Media penyimpanan portabel berbasis USB/chip yang mudah dilepas-pasang untuk memindahkan data.

5. Perangkat Lainnya (Pendukung & Ekstra)

Komponen pendukung vital di dalam sistem komputer yang memastikan seluruh perangkat dapat terhubung, bekerja stabil, dan dialiri listrik.

Perangkat Pendukung
🧩
Motherboard (Papan Induk)
Papan sirkuit cetak utama tempat seluruh komponen hardware (CPU, RAM, VGA) ditancapkan dan dihubungkan.
Perangkat Pendukung
🎮
VGA Card (Kartu Grafis)
Komponen pengolah data visual dan grafis berkualitas tinggi untuk ditampilkan ke layar monitor.
Perangkat Pendukung
🎵
Sound Card (Kartu Suara)
Komponen pengolah sinyal audio digital agar dapat menghasilkan suara jernih melalui speaker atau mic.
Perangkat Pendukung
⚡
Power Supply (PSU)
Perangkat pengubah dan penyalur arus listrik dari stopkontak ke seluruh komponen di dalam komputer.
Perangkat Pendukung
❄️
Heatsink & Kipas Pendingin
Pendingin logam dan kipas angin untuk membuang panas berlebih dari CPU agar komputer tidak *overheat*.
Perangkat Pendukung
🌐
LAN Card / Wi-Fi Adapter
Kartu jaringan atau antena penghubung agar komputer dapat terhubung ke internet dan jaringan lokal.
